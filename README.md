# Ben's Interactive Portfolio

A premium, interactive, and fully responsive portfolio website built for **Benedict Oyelewo**—showcasing his expertise as a Frontend Web Developer, Graphic/UI Designer, and Video Editor.

## 🚀 Features
- **Modern Glassmorphism UI**: Uses a sleek dark theme with glowing neon accents and translucent frosted-glass panels.
- **Scroll Reveal Animations**: Sections beautifully glide and fade into view as you scroll down the page.
- **Dynamic Projects Lightbox**: Click on any graphic design showcase to instantly pop it open in a full-resolution, immersive modal.
- **Fully Functional Contact Form**: Built-in backend-less messaging powered by [Web3Forms](https://web3forms.com/).
- **Responsive Navigation**: Includes a fluid "Scroll to Top" smart button and mobile-friendly stacking.

## 🛠️ Technologies Used
- **Vite** (Next Generation Frontend Tooling)
- **React 18** (UI Component Architecture)
- **Vanilla CSS** (Custom Global Design Tokens & Keyframe Animations)
- **IntersectionObserver API** (For Scroll Reveal triggers)

## 💻 Running the Project Locally
To run this portfolio on your own machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/abbeyzerotheorem/ben-designs.git
   cd ben-designs
   ```

2. **Install all dependencies**:
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```

4. **View in the browser**: Open up `http://localhost:5173` to see the site running live!
